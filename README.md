# Flipkart Sales Performance Analysis Dashboard
## Project Overview
This project presents a comprehensive Sales Performance Analysis Dashboard designed to transform raw Flipkart transactional data into meaningful business insights. The objective is to analyze revenue, profit, customer behavior, and product performance to support data-driven decision-making.
# Data Source
The dataset used in this project is a public e-commerce sales dataset in Excel format. It contains 100,000+ transaction records including Order ID, Order Date, Category, Region, Sales, Profit, Quantity, and Delivery Type.
# Tools & Technologies
- Excel for initial data review
- Power BI for dashboard development
- Jupyter Notebook for analysis
 - Git & GitHub for version control
# Data Cleaning & Preparation
- Removed duplicate records
- Handled missing values
- Converted date columns to datetime format
- Created calculated columns (Profit Margin %, Month, Year, Weekday/Weekend)
- Standardized column names and validated data consistency
# Exploratory Data Analysis (EDA)
The analysis focused on:
- Revenue and profit trends
- Category-wise performance
- Region-wise sales comparison
- Monthly sales trends
- Delivery type preferences
# Key Insights
- Total Revenue exceeded 135M
- Total Profit exceeded 75M
- Zone 3 generated the highest revenue
- Standard delivery is most preferred
- Health & Beauty and Fashion are top-performing categories
# Recommendations
- Increase focus on high-performing categories
- Strengthen marketing in top-performing regions
- Improve weekend promotional campaigns
- Optimize pricing strategy for low-margin products
# How to Use
1. Clone the repository using Git.
2. Install dependencies: pip install -r requirements.txt
3. Run the Jupyter Notebook file for analysis.
4. Open the Power BI (.pbix) file to explore the interactive dashboard.
